Application Full-Stack pour la surveillance en temps réel d'une flotte de machines connectées.

## Contexte du projet

Ce projet est un exercice personnel réalisé en préparation d'une alternance en tant que Développeur Full Stack chez **Secom Engineering**. L'objectif est de monter en compétence sur la stack technique et les problématiques métier de l'entreprise, notamment dans le domaine de l'IoT pour les engins mobiles.

L'application simule la remontée de données télémétriques depuis des machines, leur traitement via un back-end et leur visualisation sur un tableau de bord.
